# Vocabulary Quiz

苦手な語ほど出題されやすい、個人用の語彙学習アプリです。

登録した語彙について、意味・単語・読みを問う四択クイズを繰り返し遊べます。学習履歴はブラウザ内に保存され、誤答した語や正答率の低い語が優先的に出題されます。

## 主な機能

- 毎回変わる四択クイズ
- 意味から単語を答える問題
- 単語から意味を答える問題
- 漢字を含む語の読み問題
- カタカナ語・英字語の読み問題を除外
- 読み問題の回答後にも意味を表示
- 苦手語・未出題語を優先する重み付き出題
- 復習ノート
- 苦手ランキング
- 五十音順の語彙一覧
- 語彙・読み・意味・カテゴリ検索
- お気に入り
- 学習統計
- 今日の学習進捗
- 問題数設定
- 読み問題のON・OFF
- ライト・ダークテーマ
- 学習データのバックアップと復元

## AIによる語義生成

辞書APIが語義の区切りを返さないため、英語語釈を1つずつ候補として扱います。文脈がなければ辞書の先頭候補を使い、文脈があればAIで候補IDを1つ選択してから、その語釈だけを翻訳します。選択した英語語釈は確認メッセージに表示します。文脈による選択が必要な場合はAI呼び出しが1回増えます。複数候補は同義語の場合もあり、辞書の厳密な語義区分を復元する処理ではありません。

`worker/vocabulary-generator.js`をCloudflareの既存の生成Workerへ反映してください。AIバインディング名は`AI`です。画面側から送る`dictionaryHint`を、読み・文脈と合わせて生成に使用します。参照URLの本文を取得する処理はありません。

辞書候補を読みで絞り、読み・品詞をコード側で確定します。AIには英語の語釈と文脈だけを渡して日本語の定義文に翻訳させます。読みや補足説明をAIに作らせません。辞書資料がない場合や読み候補が複数で指定がない場合はHTTP 422で保留します。翻訳が空欄・英語のみ・見出し語の繰り返しの場合は一度だけ再試行し、それでも失敗したら入力欄を上書きせずエラーを返します。訳の正しさはAIにも依存するため、生成後の確認が必要です。

回帰テスト（Node.js 24）: `node --test worker/vocabulary-generator.test.mjs`。AIを模擬した受け渡し・検証処理のテストであり、実モデルの語義精度を測るものではありません。反映後は、多義語（例：生物／せいぶつ・なまもの）、専門分野の語、未知語で実出力を確認してください。
