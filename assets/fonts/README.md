# Interface font

`press-start-2p.ttf` is the unmodified Press Start 2P font from
https://github.com/google/fonts/tree/main/ofl/pressstart2p.
Its SIL Open Font License is included as `press-start-2p-OFL.txt`.

The font is self-hosted; the app makes no font requests to third-party servers.
`css/pixel-ui.css` opts in only interface English labels and numeric metrics.
Do not apply it to the body, quiz words, choices, readings, meanings, dictionary
entries, explanations or input fields, including English learning content.
