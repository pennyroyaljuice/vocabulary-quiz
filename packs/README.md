# 語彙パックの編集方針

- 初級100：既存の読書向け100語。今回の変更対象外。
- 中級100（version 2）：評論・報道の論理、社会の動き、人の態度や心情を表す100語。
- 上級100（version 2）：文学・思想・批評の語と四字熟語を中心とする100語。

難易度はこのアプリ内の相対的な区分であり、漢検・JLPTなどの公的な級ではありません。初級自体が読書向けのため、中級・上級もその水準に合わせています。

中級・上級の意味、補足、例文は学習用に書き起こしたものです。多義語は収録した意味に例文を合わせています。辞書の全語義を網羅していません。各語の補足は `description` に保存し、AI APIを呼び出さずにパックから登録します。

2026-09-16の編集では3パック間の見出し語重複を除き、中級の旧仮データにあった「踏襲」「形骸化」「示唆」は初級で学ぶ構成にしました。表記違いだけの「矜持／矜恃」は別項目にしていません。上級の既存見出し「人口に膾炙」は維持し、補足で「人口に膾炙する」という用い方を示しています。

読みは代表的なものを1つ登録しています。「矜持」「憧憬」には確認した別の読みも補足しました。語義・読みの確認に参照した以下の資料は一部の項目の確認用です。全200語を外部辞書と照合済みとするものではありません。参照した項目には `sources` を付けています。

## 追加前の確認とお試し

「設定」→「語彙パック」の各カードから、全100語の一覧とお試しクイズを開けます。一覧では読み・意味・補足を確認でき、語彙・読み・意味などで絞り込めます。

カードの「お試しクイズ」は10問です。一覧では10・20・100問から選べます。通常クイズと同じ問題生成処理を独立したセッションで使用し、そのパック内だけで出題・選択肢を構成します。お試しは語彙・学習記録・前回の出題履歴を保存せず、通常クイズの進行状態も変更しません。「追加する」を押した場合だけ登録します。

画面操作の確認は `tests/pack-preview-browser.cjs`（Playwright / Microsoft Edge）で実行できます。`VOCAB_TEST_URL` でサイト、`VOCAB_TEST_PLAYWRIGHT` でモジュールのパスを指定します。独立したテスト用コンテキストを使用し、利用者の保存データには触れません。

## 更新時の動作

パックを追加すると未登録の語だけが追加されます。同じ見出し語の登録済みデータや利用者の編集は上書きしません。以前の仮パックを登録済みの場合も「追加する」で未登録分を取り込めますが、登録済みの語の意味・補足は自動更新されません。

## 確認

`node --test tests/word-packs.test.mjs`

各100語、全300語の見出し重複、必須項目、出題形式に加え、実際のStorage/Quizコードで追加・再追加・既存編集の保持・クイズの完走を確認します。テスト用のメモリー内ストレージを使用し、利用者の学習データには触れません。これらのテストは語義の正確性そのものを保証するものではありません。
